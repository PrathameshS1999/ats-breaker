# ATS_Breaker: X-ray

The chosen visual direction for ATS_Breaker.

- `index.html`: open it in a browser (online, so the fonts load). It shows the whole page in this direction: scan inputs, scanning state, results summary with the rescan change, parse preview, keywords, recruiter review, fix list, an error state and the footer. The spec card lists palette, type and form.
- `preview-full-page.png`: a screenshot of the same page.

## Type and form

- **Headings, scores and labels:** JetBrains Mono, with labels in capitals and letter-spaced.
- **Body:** Source Sans 3 at 16px.
- **Corners and borders:** 4px corners and 1px slate borders. No glow and no shadows.
- **Density:** medium, with 48px between sections.
- **Status:** always shown as an icon and a word, never by colour alone.

The resume, job description and scores are invented example content.
